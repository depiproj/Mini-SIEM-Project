About IOC Enrichment

The Mini-SIEM queries multiple threat intelligence sources:

  • VirusTotal — file/URL/IP/domain reputation
  • AbuseIPDB — IP abuse reports
  • AlienVault OTX — threat pulses

Without API keys, the system uses an intelligent offline simulation mode that never fails and provides realistic threat intelligence data for testing.

Add API keys to .env to enable live lookups.

🔒 Data Privacy & Transparency Statement

Honest ML Processing: To preserve institutional privacy and data minimization standards, your uploaded raw security logs or packet fields are processed strictly in real-time for instant classification.

No analysis payloads, logs, or network features are ever retained, stored, or synthesized to retrain background machine learning models. Standard alert logs remain fully under your local data retention controls.
